શ્રી વિહત મેલડી ધામએડમિન પેનલ

એડમિન લૉગિન

પાસવર્ડ કે ચકાસણી કોડ ખોવાઈ ગયો?

આ ખાનગી વ્યવસ્થાપન ક્ષેત્ર છે. દરેક કાર્ય ઓડિટ ઇતિહાસમાં નોંધાય છે.

પાસવર્ડ કે ચકાસણી કોડ ખોવાઈ ગયો?

આ પાનું હાલ શું બતાવે છે — ચકાસણી બાકી

સુરક્ષા માટે પાસવર્ડ જાતે બદલી શકાતો નથી. મંદિરના સુપર એડમિનનો સંપર્ક કરો — તેઓ તમારું ખાતું ફરી ચાલુ કરશે.

તમારા પાસવર્ડ કે કોડ કોઈને ફોન કે મેસેજમાં ન જણાવો.
